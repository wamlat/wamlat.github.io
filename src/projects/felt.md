I built this project alongside Ryan Shin. This project implements a full-stack
live poker platform with a sophisticated hand state machine managing game phases
from pre-flop through showdown. It supports No-Limit Hold'em and Pot-Limit Omaha
(4/5/6-card), complex all-in side pot splitting, and host-configurable options
like run-it-twice, rabbit hunting, auto-deal, and straddles. The frontend is a
single-page HTML5 poker table UI with animated card dealing and real-time
Socket.IO communication.
